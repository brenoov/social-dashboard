O que é este projeto?
---------------------
NÃO é mais o app que está no ar. É onde ficam guardadas as versões
ANTIGAS do painel (de antes da migração para Vue) e alguns mini-apps
à parte. O app publicado hoje mora em `src/` (na raiz do repo) e é
montado pelo Vite — veja o LEIA-ME.txt da raiz.


As VERSÕES antigas do dashboard (arquivos .html, histórico)
-------------------------------------------------------------
  central-inteligencia-v1.3.html, v1.2-preview.html, v1.1.html,
  index.html
     -> "Fotografias" congeladas do dashboard monolítico de antes do
        Vue, guardadas como histórico. NENHUMA delas é publicada —
        o que vai para o ar é o build de `src/` (na raiz do repo).
        Não edite para adicionar funcionalidade nova.


Subpastas
---------
  escritorio-3d/ -> O "Escritório 3D" dos agentes: página estática à
                   parte, em three.js. Não faz parte do app Vue nem
                   do build dele. (veja escritorio-3d/LEIA-ME.txt)

  backup/       -> Cópias de segurança com data, feitas antes de
                   mudanças grandes (ex.: ...pre-noticias.bak.html) e
                   um backup.sh + backup.log. Servem para voltar atrás
                   se algo quebrar. (Os .bak.html e .log são ignorados
                   pelo git — ficam só na sua máquina.) (veja
                   backup/LEIA-ME.txt)

  redes-sociais/-> Um SUB-PROJETO mais antigo, focado em redes
                   sociais, com o próprio coletor em Python e um
                   dashboard v1.0. (veja redes-sociais/LEIA-ME.txt)


Arquivos
--------
  vercel.json   -> Cabeçalhos de segurança específicos deste projeto
                   (proíbe iframe, evita "adivinhação" de tipo de
                   arquivo, etc.) — não é usado pelo deploy da raiz.


Para iniciante
--------------
Estes arquivos .html são só referência histórica (arquivos únicos e
MUITO grandes, com HTML/CSS/JavaScript tudo junto). Para entender o
sistema que está no ar hoje, veja `src/` (na raiz do repositório).
