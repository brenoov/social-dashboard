 PASTA: projetos/   —  MINI-APPS À PARTE (não são o app Vue)
==================================================================

O que é esta pasta?
-------------------
Guarda projetos separados do app principal (que hoje vive em `src/`
e é publicado via build do Vite/Vue — veja o LEIA-ME.txt da raiz).
Hoje há um sub-projeto:

  central-inteligencia/  -> Snapshots antigos do dashboard (versões
                            v1.1/v1.2/v1.3 em HTML único, de ANTES da
                            migração para Vue) + o Escritório 3D dos
                            agentes + um coletor legado em Python.
                            Nada daqui entra no build do app Vue.
                            (veja central-inteligencia/LEIA-ME.txt)


Para iniciante: por que isso não é o site no ar?
-------------------------------------------------
O site publicado hoje é montado pelo Vite a partir de `src/` (comando
`npm run build`, gera `dist/`). O que está aqui em `projetos/` é
histórico (as versões antigas do painel, antes do Vue) e mini-apps
independentes (o Escritório 3D, o coletor Python antigo) — nenhum dos
dois passa pelo build nem é servido pela Vercel deste repositório.
